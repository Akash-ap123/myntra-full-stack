# Myntra Full Stack Clone

A full-stack e-commerce web application inspired by Myntra, built using React, Redux Toolkit, Node.js and Express.js.

## Features

- Product listing
- Add to Bag functionality
- Shopping Bag
- Redux state management
- Backend API
- Responsive UI

## Tech Stack

- React.js
- Redux Toolkit
- JavaScript
- Node.js
- Express.js
- Vite
