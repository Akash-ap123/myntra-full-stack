# Myntra Full Stack Clone

A full-stack e-commerce web application inspired by Myntra, built using React, Redux, Node.js and Express.js.

## Features

- Product listing and browsing
- Add to Bag functionality
- Shopping bag/cart management
- Dynamic product data
- Redux for state management
- Backend API using Node.js and Express.js
- Responsive and user-friendly UI
- Product images and details

## Tech Stack

- React.js
- Redux Toolkit
- JavaScript
- CSS
- Node.js
- Express.js
- REST API
- Vite

## Project Structure

- `myntra-react-clone/` — Frontend application
- `backend/` — Backend server and product data

## Purpose

This project was built to understand and practice full-stack web development, including React frontend development, state management, REST APIs, and backend integration.
